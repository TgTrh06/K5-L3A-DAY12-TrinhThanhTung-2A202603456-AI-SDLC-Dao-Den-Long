Game premise, Mây and Bóng Mực: VinUni AI20K Day 12 lab.
All in-game geometry/materials are generated in this repository; no external art.
Three.js: MIT, https://github.com/mrdoob/three.js/blob/dev/LICENSE

Node.js: MIT, https://github.com/nodejs/node/blob/main/LICENSE
System font and platform emoji are rendered by the user's operating system.

Watercolor visual update: user-supplied reference images guided palette and art
direction only. No pixels from the references are distributed in the game.
Paper washes, cloud scrolls, grain, sky, ground, glow, HUD icons and geometry are
procedurally authored in src/visuals and src/style.css. No new art dependency.

Audio is synthesized at runtime with the Web Audio API in src/audio.js; no
external music or sound recording is bundled. OpenAI Codex assisted source code,
tests, documentation and procedural game content across the four SDLC phases.
No external image or audio generation service was used. Chrome/Chromium is used
only as the local benchmark renderer; it is not redistributed in the release.
